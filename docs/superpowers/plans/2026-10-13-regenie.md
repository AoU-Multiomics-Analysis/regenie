# REGENIE implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement the tasks in this session.

**Goal:** Build and push a Terra REGENIE workflow that accepts PLINK 2 file sets.

**Architecture:** A Python CLI checks localized files and runs REGENIE. A WDL fits step 1 once and scatters step 2 across file sets.

**Tech stack:** WDL 1.0, Python 3.11, REGENIE 4.1.2, PLINK 2, micromamba, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-10-13-regenie-design.md

## Global constraints

- WDL 1.0 and Terra managed Cromwell.
- File creation occurs only inside tasks.
- Files that tasks open remain typed File inputs until command rendering.
- Named CLI arguments and safe quoting. No JSON argument wrappers.
- No local Docker build. No Terra submission.
- Automatic image builds require a change to a script copied into the image.

## Review focus

- Localized filenames with spaces, apostrophes, dollar signs, and shell syntax remain literal.
- Prediction lists from another task contain obsolete absolute paths.
- Optional inputs are absent and must not create empty CLI arguments.
- Binary and quantitative settings cannot be mixed.
- The workflow must reject file-writing expressions in scatters, calls, and outputs.
